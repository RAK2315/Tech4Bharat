- Recovered context: one builder using Codex; later frontend preference TypeScript; free API/services only; no added hardware; no factory data, representative phone images, factory access, or contacts established. Recorded milestones: registration November 10, idea November 15, prototype December 15, finale December 27, 2026. Official team-size conflict unresolved. User will perform a later timed review exercise; its results are not available yet.
- Available CPU: AMD Ryzen 7 260, 8 physical / 16 logical cores. RTX 5050 laptop and integrated graphics detected, but CPU-only execution is selected. No phone tested. Bundled Python 3.12.14, isolated local environment.
- Product: VisA PCB1, one board design, its dataset-provided approximately top-down view. Supported *benchmark defect labels*: Bent, Melt, Scratch, Missing, per original `utils/id2class.py`. Automated quality gate is only a limited blur/exposure check; it does NOT verify this whole capture contract or prove defect visibility. No solder, electrical, dimensional, hidden, or microscopic assurance.

Original-byte equivalence is unverified unless independently checked. Do not silently substitute synthetic images.

## Split and leakage rules — fixed before inference

- Use the mirror's source train/test partitions. Source training rows must all be normal; assert this.
- Compute full decoded-pixel SHA256 and perceptual hashes before inference. Union exact duplicates, and conservative near-duplicates (64-bit pHash Hamming <=2 AND mean absolute difference of 64x64 RGB <=2/255). These checks are appearance checks, not proof of distinct physical boards.
- If a group spans original train/test, keep original train members and quarantine original test members. Within original test, keep an entire group in one assigned partition. No physical serial IDs are established: physical-instance leakage cannot be ruled out and must be reported.
- Deterministic ordering: SHA256(seed=4217 + group key). Select 100 normal reference groups and next 100 normal calibration groups from source train; remaining train groups unused. All members of selected groups stay together; use one canonical image per group to avoid duplicate weighting.
- Split original defective test groups deterministically: first 20 groups for calibration, remainder for untouched final test. Original normal test groups remain final test. This deliberately changes the official benchmark protocol; report as custom validation, not official VisA performance. If grouping changes available counts, record actual counts rather than relaxing leakage rules.
- Test labels/masks may be used for split/dedup manifests and final evaluation, never threshold choice, parameter choice, or retraining. Results are descriptive after one frozen run. No tuning on final failures.

## Fixed approaches

- Common image resize: full frame to 224x224, PIL bilinear; no center crop, no test-specific alignment. This can hide small defects and is a stated limitation.
- Simple reference baseline: per-channel brightness-centering to common mean, nearest normal reference by global squared RGB difference; anomaly map is smoothed local squared residual, score mean of highest 1% map pixels. Only reference images populate the bank.
- Established method: PaDiM (Defard et al., https://arxiv.org/abs/2011.08785), ResNet18 ImageNet1K V1 frozen pretrained features from layers 1/2/3, nearest-upsampled and concatenated; deterministic 50-channel subset; spatial Gaussian mean/covariance from the same 100 normal references; covariance regularization 0.01 I; Mahalanobis distance, Gaussian smoothing sigma 4; maximum-map image score. This is a compact configured reimplementation, not the authors' exact benchmark configuration. Native CPU first, four threads.
- Quality gate fixed: original image minimum side >=224; mean luminance [0.05,0.95]; clipped luminance fraction <=0.50 (luma <0.01 or >0.99); variance of grayscale Laplacian on 224x224 >=20. Reject -> abstain / request retake, not normal. No model-score uncertainty abstention is implemented. Both methods share this gate.
- Thresholds chosen only on quality-accepted calibration rows: enumerate score boundaries, constrain false-positive rate on accepted normal calibration images <=10%, maximize defect recall, break ties by fewer false positives then larger threshold. If no normal/defect calibration accepted, fail calibration and stop. Freeze thresholds before final-test scores.

## Measurements and provisional decision rules

- Counts: TP/FN/FP/TN and quality-abstained normal/defective; numerator/denominator for every rate; defect flagging recall = TP / ALL defective test items including abstentions as not caught. Also report conditional recall among accepted images; do not hide abstentions.
- FPR = FP / accepted normal test items; also FP / all normal test items. Precision = TP/(TP+FP) at observed test prevalence, not a factory estimate. Wilson 95% intervals for recall/FPR/precision are descriptive, not industrial certification.
- Coverage = accepted/test count. Retake requests = quality-gate rejections. These are model-assessed images, not human-completed inspections.
- Latency: decode+preprocess+quality gate+inference+score per image on this CPU, median/p95 and accepted/abstained breakdown; report initialization, fitting, native and optional browser separately. Exclude artifact rendering from per-image inference. Human capture/review/reporting time is UNMEASURED until participant records it. No fabricated timing savings.
- Provisional screening pass: >=90% all-defect flagging recall, <=10% FPR on accepted normals, >=90% coverage, warm p95 <=5sec/image on tested CPU. These are engineering stop/go screens, not validated industrial requirements. Compare learned model to simple baseline; a learned model must justify complexity, ideally >=5 percentage-point recall gain at similar FPR or equivalent detection with a clearly measured runtime/workload benefit. If neither meets screens, no-go on MVP until scope/data changes.
- Fixed synthetic stress: apply brightness multipliers 0.6 and 1.4 and Gaussian blur radius 2.0 separately to all final-test images. Never add these to training/calibration. Label them transformed copies, not independent products; report separately and paired with originals, no pooled confidence claims.
- Optional prevalence scenarios use measured recall/FPR with explicitly hypothetical prevalence and invariant-performance assumption. Never use to claim actual factory defect rates.
- Browser candidate: export compact feature extractor; use same RGB/[0,1]/normalization/resize and stored Gaussian parameters; compare native scores, decisions, preprocessing, model bytes, cold/warm latency and failures on this computer. No phone-compatibility claim. Browser is optional continuation, not prerequisite to native accuracy result.

## Separate software and human exercises

- Fictional accounting fixture: unique product IDs, duplicate content and distinct views, rework/reinspection history, unresolved and uninspected products; immutable inspection events; current disposition distinct from historical defect count; owner acknowledgment blocked until completed; no automatic approval. Assert expected counts. Explicitly fictional human decisions; no inference-performance evidence.
- Sample report: real benchmark model observations mapped to fictional product/batch IDs; simulated human decisions visibly marked; never sign on user's behalf. Coverage, flags, unresolved items, source attribution, model/config/threshold hashes, missing checks, and approval state included.
- Timed human review: prepare separate balanced/disjoint matched manual and assisted sets, never repeated same images; user self-times review including retakes and reporting. Small convenience exercise, not expert inspection or industrial efficacy. Store responses; ground truth reveal after completion. No feedback/contact invented.
- Manufacturer/buyer exercise: ask about last rejection, current alternatives, how report changes a decision, extra work, missing evidence, approved defect examples, and willingness to trial. No external contacts authorized.
